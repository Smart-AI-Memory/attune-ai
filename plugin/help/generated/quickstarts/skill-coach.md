# Quickstart: Use `/coach`

Get progressive, structured guidance on any topic — directly in your Claude Code conversation.

## Usage

```
/coach <topic>
```

**Examples:** `security-audit`, `code-review`, `performance-tuning`

## What to Expect

Running `/coach` returns structured coaching steps tailored to your topic, helping you build understanding incrementally rather than all at once.
