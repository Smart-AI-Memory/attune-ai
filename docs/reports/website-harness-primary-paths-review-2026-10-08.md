- Both FAQ surfaces present the seven shared Harness questions first.

  `python -m pip install 'attune-harness[all]==1.3.0'`, a separate environment,
  version confirmation and a deterministic local example. Agent setup,
  Redis/Voyage requirements and possible provider charges remain explicit.
- The older Platform/plugin/workflow showcases are removed from the Docs
  entry page. The standalone reader has a brief secondary reference.
  Existing static Attune AI documentation content is retained, using the
  green shared theme published in PR2550.
- The shared navigation makes Harness benefits, documentation, context
  and collaboration prominent. Attune AI, Forms and RAG remain available
  as project references. No Help owner source or Help-link proposal is
  integrated by this change.
- Older authored FAQ and memory/verification copy now qualifies selected
  checks, data destinations, host compatibility and license conditions.
  It does not claim zero hallucinations, universal model interoperability,
  an active embedding-provider migration or guaranteed correct output.
- Native planning/building are experimental in the cited 1.3.0 release.
  Browser forms support draft/preview/intent approval, with no browser
