# Concept: Coach

## What

Coach provides progressive, layered help on any topic. Each time you invoke it, you go one level deeper — moving from conceptual understanding, to step-by-step procedures, to detailed reference material.

## Why

Use Coach when you want to build understanding gradually rather than receiving all information at once. This approach reduces cognitive load and lets you stop at the level of detail you actually need. See the full reference documentation for a complete description of what Coach checks and the recommended situations for using it.

## How

Run `/coach` to get started. Coach will guide you through each layer interactively, prompting you to continue deeper when you're ready.
