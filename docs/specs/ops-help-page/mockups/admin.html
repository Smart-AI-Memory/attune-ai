How to fix

  1. For incomplete sets, run attune-author generate <feature> --all-kinds from the project root.
  2. For stale templates, the same command regenerates only the kinds whose source hash drifted.
  3. Review the regenerated content before committing — the polish pass is LLM-assisted; spot-check for facts you care about per the existing hallucination-shapes lesson.
