# Roundtable reports — local-first

Full deliberation transcripts are **machine-local** development
data: they live at `~/.attune/reports/roundtable/` on the
moderator's machine and are not tracked or distributed.

Files in this directory are **curated stubs**: the chair-promoted
sections of each deliberation (rulings, syntheses) kept in-repo so
spec provenance citations resolve, plus a pointer to the local
transcript. Policy and rationale:
[docs/specs/local-first-reports/](../../specs/local-first-reports/requirements.md).

Note the boundary honestly: reports migrated on 2026-07-31 remain
in git history — this policy controls future distribution and
repository size, not retroactive privacy.
