# FAQ: What should I know about gh repo create --source <path> --push is a one-shot for new sibling repos?

## Answer

Creates the GitHub repo, adds it as `origin` remote in the local path, and pushes HEAD in a single command. Flags to use: `--public --description "..." --homepage "..." --source <path> --remote origin --push`.
