# Quickstart: Install attune-ai

Install the `attune-ai` package from PyPI:

```bash
pip install attune-ai
```

**Result:** The `attune` CLI is now available in your terminal.

**Next step:** Run `attune doctor` to verify your environment is configured correctly.
