# Socratic

## Definition

**Socratic** — A discovery-first interaction style in which the system leads through targeted questions rather than presenting immediate answers or solutions.

## Context

This term describes a core interaction pattern used in the **attune-ai** codebase. A Socratic approach prioritizes understanding user intent, context, and goals before offering responses — guiding the conversation progressively rather than front-loading information.

## Key Characteristics

- **Question-driven** — Responses favour clarifying questions over assumptions
- **Iterative** — Understanding is built incrementally across a conversation
- **User-centred** — The focus remains on uncovering what the user actually needs, not just what they literally asked
