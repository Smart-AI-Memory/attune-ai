This lesson practices the current Harness 1.7.0 workflow with fixed local command participants. The worker supplies known reference code; the protocol reviewer does not judge its quality. The protected tests check the actual program. No model or provider is called.

For real implementation, your assistant needs participants suited to the task and the execution authority you choose. Start with the offline practice to understand the decisions.

Choose your starting path: this bounded reporting exercise starts from a clear goal. If your real project has several workflows or unresolved requirements, use the goal-driven and spec-driven reference to choose the preparation it needs before accepting a plan.
