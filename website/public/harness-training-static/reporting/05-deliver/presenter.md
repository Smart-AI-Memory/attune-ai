# Presenter notes: Make the tool usable

Derived from this lesson’s JSON.

## section-1: Hand off the report you built

Start with the HTML report and the evidence you just reviewed.

- Have learners reuse their report and task evidence when available.

## section-2: Gather the files for your handoff

Use the report and original sample CSV from your practice project.

- Keep the checked example available for people starting from scratch.

## section-3: Show how to open or recreate the report

Give the recipient the report path first.

- Opening the existing report is the main path. Use the ZIP command only in the checked example folder.

## section-4: Give the recipient one way to check it

Share an expected result the recipient can find in the HTML.

- One concrete comparison makes the handoff usable. Leave extra checks available as references.

## section-5: Try a separate input copy

Optional practice if you want to see how the report responds to a change.

- Place the optional input copy and output beside the project so the protected inputs stay intact.

## section-6: Write a short handoff

Give the recipient a file to open, a result to look for and the evidence you used.

- Check that the handoff uses the learner’s actual report and results.

## section-7: Check that someone can use the handoff

Read your note as a recipient who has never seen the practice folder.

- Use the check to confirm that the recipient can preserve an existing report.
