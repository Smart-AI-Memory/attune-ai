## Sequencing

- **T1** independent — ship-ready alone if catalog slips.
- **T2 → T3** (catalog skill depends on the tool, if D-CAT-a chosen). If
  D-CAT-b (CLI) is chosen at review, T2 drops and T3 routes to CLI.
- **T4** last — gates the PR.

One PR. Concerns: `impl` (T1–T3) + `test` (T4) + `release-notes`
(CHANGELOG: two new skills + optional tool). No `regression-guard`
(additive); no `migration` (additive).
