What the inspected base install supplies¶

Get started with published 1.6.0 for current installation guidance; it requires Python 3.12 or later. This reference retains its 1.5.1 dependency and walkthrough identities. Published 1.5.1 retains its Python 3.10 minimum. You do not need to install attune-forms separately for the Harness forms journey.

For example, install 'attune-harness[redis]==1.5.1' in the isolated environment if the requested integration needs Redis. all combines Redis and Voyage; the local examples in this Help Center need only the normal base install. Installing an extra does not grant execution authority or authorize spending.

1.6.0 Redis requirements and limits¶

Published 1.6.0 pins redis-py 5.3.1. The retained disposable-service check used Redis 7.4.7 with Search 2.10.20 on macOS arm64 and Python 3.12.2. All 77 assertions passed against the exact published wheel, including unavailable-service behavior and clean-restart persistence. Read the 1.6.0 release record for the artifact and check boundaries. This does not qualify a Windows Redis service, TLS/ACL success, abrupt-crash recovery or automatic session recall. Preserve service data and hooks. The optional generation reader consumes compatible existing state. It does not create a writer, publish generations or deliver automatic fresh-session recall. A new Redis projection writer and RedisVL adoption remain outside 1.6.0.

Missing optional capabilities report an unavailable result. Read the feature and reason, select its documented supported path, and configure only the dependency or service needed for that task. Installing an extra does not configure a server or authorize provider calls. Unknown or untested behavior is not automatically classified unsupported.
