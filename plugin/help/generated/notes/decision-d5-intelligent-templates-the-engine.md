# Design Decision: Intelligent Templates as the Engine

## Context

Documentation stack architecture decision.

## Content

Intelligent templates function as the **engine** of the documentation stack: context goes in, a populated template comes out. Autogenerated topics are one **use case** of that engine — the system scans code and produces help pages without manual authoring.

The engine itself is general-purpose. Autogenerated topics are its first and primary application, but the same mechanism can power any workflow that maps structured context to rendered output.
