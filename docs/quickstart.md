## Quick Install

```bash
# Install
pip install attune-ai[developer]

# Set API key
export ANTHROPIC_API_KEY="sk-ant-..."

# Install slash commands for Claude Code
attune setup

# Run your first workflow
attune workflow run security-audit --path ./src
```
