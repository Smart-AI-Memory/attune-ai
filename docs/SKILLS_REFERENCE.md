# Skills Reference (moved)

This page predates the plugin's skill growth and is no longer
maintained here. Skills are discovered from live registries, not
from a hand-written list — use the surfaces below.

## Where to look instead

- **Browse live:** run `/catalog` in Claude Code — it enumerates
  every workflow, wizard, and tool from the live registries.
  `/help` gives the quick command reference.
- **Source of truth:** `plugin/skills/<name>/SKILL.md` (one
  directory per plugin skill) and repo-level
  `.claude/skills/<name>/SKILL.md`.
- **Projected mirror:** `.agents/skills/` is generated by
  `scripts/sync_agents_skills.py` — never hand-edit it.
- **CLI:** [reference/cli-reference.md](reference/cli-reference.md)
  documents the `attune` command-line interface.
