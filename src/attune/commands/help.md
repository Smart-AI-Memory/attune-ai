# Attune Command Reference

## Primary Commands

| Command | What it does |
| ------- | ------------ |
| `/spec` | Spec-driven development — brainstorm, plan, execute with approval |
| `/attune` | Guided discovery — asks what you need, routes you there |
| `/security` | Security audit on a path |
| `/smart-test` | Find test gaps, generate tests for uncovered code |
| `/release` | Release prep, security checks, publish |

## Developer Tools

| Command | What it does |
| ------- | ------------ |
| `/dev` | Debug, commit, PR, code review, refactoring |
| `/code-quality` | Code review + bug prediction |
| `/fix-test` | Auto-diagnose and fix failing tests |
| `/refactor` | Refactoring analysis and roadmap |
| `/deep-review` | Multi-pass security, quality, and test gap review |

## Planning and Docs

| Command | What it does |
| ------- | ------------ |
| `/plan` | Feature, refactor, and architecture planning |
| `/brainstorm` | Guided brainstorming with structured output |
| `/doc-gen` | Generate documentation from source code |
| `/remember` | Store and retrieve persistent memory |

## Advanced

| Command | What it does |
| ------- | ------------ |
| `/agent` | Create and manage custom AI agents |
| `/wizard` | Guided multi-step wizards |
| `/bulk` | Batch API processing (50% cost savings) |

## CLI

```bash
attune setup          # Install commands for Claude Code
attune workflow run X  # Run a workflow directly
attune doctor         # Health check
attune auth status    # Check auth configuration
```

## Tips

- Type `/attune` if you're not sure which command to use
- Type `/spec` to start a new feature from scratch
- All commands use guided questions before executing
