Use case

This Twilio toll-free number is used solely for the account holder’s personal developer-workflow notifications and interactive prompts. The only recipient of messages sent from this number is the account holder’s own personal mobile phone (+1 (843) 908-9497). No messages are sent to customers, leads, marketing lists, or any third party.

How consent is given

The account holder is both the sender and the sole recipient. By configuring the recipient phone number in the application’s private credentials file (~/.twilio.env), the account holder explicitly opts in to receive messages from this number.

Date of consent: 2026-05-10. Consent recorded by: Patrick Roebuck.

Message types and frequency

  • Notifications — short status updates from local developer tooling (e.g. build complete, CI failure, long-running task finished).
  • Interactive prompts — short questions from local developer tooling that expect a free-text reply (e.g. “Should I deploy v3.6.1 now? (yes/no)”).

Estimated frequency: fewer than 20 messages per day on average, triggered manually by the account holder. Messages are not periodic or promotional.

Sample messages

  • twilio-bridge test from your laptop — if you got this, outbound is working.
  • [Q ab12] Should I ship the PR? Reply to answer.
  • Build attune-ai 3.6.1 finished. 0 failures.

Opt-out

The recipient may opt out at any time by replying STOP (Twilio honors this automatically). Sending will not resume unless the recipient replies START. The account holder may also remove the recipient phone number from the credentials file at any time.
