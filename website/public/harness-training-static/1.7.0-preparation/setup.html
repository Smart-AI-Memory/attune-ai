Select a practice runtime

Use Bash or another POSIX shell on macOS or Linux. Install uv and Git if needed. The commands download the public course source and install Harness and pytest in a new directory. After this setup, the lesson runs offline.

COURSE_WORK="$(mktemp -d)"
COURSE_WORK="$(cd "$COURSE_WORK" && pwd -P)"
git clone --depth 1 https://github.com/Smart-AI-Memory/attune-harness.git "$COURSE_WORK/source"
uv venv --python 3.12 "$COURSE_WORK/.venv"
uv pip install --python "$COURSE_WORK/.venv/bin/python" 'attune-harness==1.7.0' 'pytest==9.1.1'
. "$COURSE_WORK/.venv/bin/activate"
python -c "from importlib.metadata import version; print(version('attune-harness'))"
cd "$COURSE_WORK/source/training/1.7.0-preparation"

Expect 1.7.0. Keep this terminal open for lesson 2. You are in the course folder with practice.py and its example files. These files are in the course checkout. The wheel provides the runtime.

The release record lists the published wheel hash. The November 5 course check records its original, separately built wheel.
