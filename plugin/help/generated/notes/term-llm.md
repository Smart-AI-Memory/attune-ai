# LLM

**Large Language Model**

A Large Language Model (LLM) is a type of AI model trained on large volumes of text data, enabling it to understand and generate human language. In the context of attune-ai, LLMs serve as the core intelligence layer powering natural language understanding, generation, and reasoning capabilities.
