Browse all goals for prompts, instructions and review points across 21 goals and six testing FAQs. Start with Learn before you build, or choose planning, implementation, verification or saved work.

Check the version before starting¶

Get started with Harness 1.6.0 to install the runtime, check a local result, connect your assistant and choose goal-driven or spec-driven development. Its release record identifies the published artifacts and their verification limits.

The historical 1.5.1 installation guide and release record retain their original source, artifacts and limits. Other guides keep their stated versions; they are not relabeled as 1.6.0 observations.

Attune AI is deprecated. Use Harness for new work and read the migration guide before changing an existing setup. Preserve working environments, memory sources and writer settings while validating the journeys you need.

Keep the decisions separate¶

Opening a form, saving answers, approving intent and authorizing execution are separate actions. A saved or accepted request does not start a build or grant a paid call. Each walkthrough states its expected result and what it does not establish.

Historical 1.3.0 and candidate walkthroughs remain in the Harness repository with their original source and artifact records. Harness owns and builds this Help Center; its 1.5.1 release record distinguishes software checks from walkthrough and platform acceptance.
