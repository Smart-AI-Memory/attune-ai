1. **MI-1:** “One verdict per surfaced item” is not achievable if rotation has already removed surfacing records, and the draft leaves this as an open question despite making missing pairs a hard failure. Resolve by defining a session-scoped snapshot/read boundary before `_rotate_if_huge()` can disrupt correlation, or weaken completeness to all recoverable surfacings (pack items 2 and 4: `surfacing_id` join key and `_rotate_if_huge()`).

2. **MI-1:** The transcript tail may contain no evidence about an item surfaced earlier in a long session, so forcing `acted_on`, `ignored`, or `wrong` conflates “not present in the bounded tail” with “ignored.” Add an explicit rule that insufficient transcript evidence produces `unscored`, or provide a probe demonstrating `_read_transcript_tail(transcript_path, max_chars)` reliably covers each surfacing’s subsequent use (pack item 4: `_read_transcript_tail` is bounded).

3. **MI-1:** The requirement does not specify how the hook selects only the current session’s surfacing events, handles duplicate events, or behaves when `session_id` is absent or reused. Define filtering and idempotency semantics—prefer one verdict per unique item join key per session—and test repeated Stop-hook execution against the same JSONL (pack item 2: events carry `session_id`, and verdict identity is `(surfacing_id, lesson_id|rule_id|finding_id)`).

4. **MI-1 / Non-goals:** Requiring `source event type` on `memory_signal` is a new event-schema decision, while the non-goal says STEP 1 schemas remain unchanged “beyond adding the new memory_signal event type.” Clarify that STEP 1 event schemas remain immutable but the new `memory_signal` schema may include `source_event`; otherwise derive it through the `surfacing_id` join (pack item 2: STEP 1 event types and join key).

5. **MI-2:** The “wrong” fixture expects a nondeterministic Ollama call to return one exact label, which is not a stable acceptance test. Specify a versioned prompt, model tag, deterministic inference settings, and parse contract; use a controlled scorer response for semantic unit tests while reserving the real Ollama run for an integration receipt (pack item 6 supplies the stale `/recall` datum, but not deterministic model behavior).

6. **MI-2 / Open question 5:** Malformed, partial, or missing per-item model output has no defined mapping, so the exact four-label schema does not guarantee one valid record per item. Ratify that every parsing failure or omitted item becomes `unscored`, consistent with “a garbage label is worse than none” (pack items 3–4: Ollama failure must remain unscored and heuristic fallback is only for findings).

7. **MI-3:** “Only model call is the local Ollama endpoint already used by `_extract_via_ollama`-style calls” is too loose to constrain implementation and conflicts with “no network egress” if a probe treats loopback HTTP as network traffic. Define allowed transport as loopback/Unix-local Ollama only, reject non-loopback configured endpoints, and probe that no remote host is contacted (pack items 3–5: local Ollama and local-only telemetry).

8. **MI-4:** “Completes its existing stash duties” under an unreadable transcript is potentially infeasible because transcript reading is itself part of the existing hook path; the draft does not distinguish preservation of independent duties from impossible transcript-derived work. Define the exact invariant as successful hook exit plus preservation of duties whose inputs remain available, then test failure isolation around verdict scoring (pack item 4: `session_stash.py` reads the transcript and the hook must never block session end).

9. **MI-5 / Open question 2:** The noise ratio formula prematurely resolves the explicitly unresolved meaning of `ignored`. Move `ignored` treatment out of the normative formula until ratified, or report separate `wrong_rate`, `ignored_rate`, and combined candidate-noise rate so downstream interpretation remains reversible (pack item 1: measure tail-prevention net of noise; it does not define ignored as noise).

10. **MI-5:** Aggregation lacks a scope and deduplication contract. Global counts across the entire JSONL can mix sessions and repeated Stop-hook verdicts, so define filters—at least session/time range—and a duplicate policy keyed by the full verdict identity before computing ratios (pack item 2: per-item verdicts use `(surfacing_id, lesson_id|rule_id|finding_id)`).

11. **MI-5:** “Caption no longer claims the denominator is missing when verdict data exists” is too broad: verdicts may all be `unscored`, orphaned, or outside the rendered estimate’s population. Change the condition to require at least one valid scored verdict in the same aggregation scope as the upper-bound estimate; otherwise retain the missing-denominator warning (pack item 4: `estimate_intervention_signal` is an upper bound and its caption must accompany all renderings).

12. **MI-6:** An integration run with Ollama absent proves persistence and degradation, but it does not prove the advertised scoring pipeline or that `acted_on`, `ignored`, and `wrong` can survive a real model round trip. Require two receipts: a mandatory keyless/unscored filesystem round trip and an Ollama-available real-scoring receipt that may be environment-gated but must be recorded before release (pack items 3 and 5: verdict scoring uses Ollama, and hook pipelines require a non-mocked round-trip receipt).

13. **MISSING:** There is no latency or call-budget acceptance criterion even though Stop-hook completion must not block and the draft acknowledges per-item versus batched calls as unresolved. Ratify one bounded call per session or surfacing batch, an explicit total timeout, and a probe showing timeout converts all unresolved items to `unscored` while the hook exits successfully (pack items 3–4: scoring occurs in the Stop hook and Ollama timeout must degrade safely).

14. **MISSING:** Transcript text and surfaced memory content are untrusted prompt inputs, but no requirement prevents them from overriding the labeling contract or eliciting non-schema output. Add prompt-delimiting and strict output-validation requirements, with adversarial transcript fixtures that attempt instruction injection and must yield only validated labels or `unscored` (pack items 3–4: the scorer consumes transcript tail through a local model and guessed labels are forbidden).

VERDICT: needs-revision, and the single most important item is **MI-1: bounded transcript tails cannot justify mandatory scored verdicts for every surfaced item; insufficient evidence must map explicitly to `unscored`.**
