# FAQ: What should I know about apply lessons by problem, not by keyword?

## Answer

The `sentence-transformers removed — 0.4% savings, 420MB` lesson is about **semantic caching** (match similar queries to cached responses). It does NOT generalize to **RAG retrieval** (match queries to documents).

