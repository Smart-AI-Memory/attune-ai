Before you begin¶

Complete Get started in a fresh working directory. Keep the published 1.5.1 environment active. R is the absolute release checkout at commit ebb5b03b8a4398325df7ddabd28c08186451452e, as set in Get started; its example files are not in the wheel. These examples use a POSIX shell and canonical paths. On macOS, use /private/tmp instead of the /tmp symlink. Choose unused practice directories. Windows desktop and shell journeys remain unqualified.

Prepare the local corpus¶

Copy the example from the release checkout before retrieving or writing reports:

E="$PWD/training-research"
cp -R "$R/examples/local-workflow" "$E"

Choose an unused E directory outside the release checkout. The base install includes local retrieval and verification. A fresh copy protects prior reports.

Retrieve sources and verify a link¶

1. Retrieve local evidence¶

attune-harness retrieve "quartz retention policy" --corpus "$E/project" --output "$E/retrieval-report.json"

2. Inspect the sources¶

Read retrieval-report.json, then project/reference.md. Inspect both returned sources, guide.md and reference.md, including excerpts and hashes.

3. Check the supported link claim¶

attune-harness verify "$E/project/guide.md" --context "$E/context.json" --output "$E/verification-report.json"

4. Inspect verification¶

Read verification-report.json. Check status, passed, result.coverage and result.semantic_ran.

Expected result: Retrieval returns two Markdown sources. Verification returns verified, passed: true, result.coverage.total: 1 and result.coverage.verified: 1. The links claim refers to reference.md at line 3 of the sample guide.

Limit: result.semantic_ran is false. This checks link validity; it does not establish policy correctness. The example is local and makes no model or Voyage call. Choose and authorize paid retrieval separately when a real task needs it.
