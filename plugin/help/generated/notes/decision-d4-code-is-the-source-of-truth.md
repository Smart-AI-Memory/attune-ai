# Design Decision: Code Is the Source of Truth

## Context

Documentation stack architecture decision.

## Content

`contextual.py`, `discovery.py`, and `suggestions.py` evolve into **consumers** of the template registry — they are not replaced, but upgraded. Rather than maintaining their own pattern lists and tip definitions, these modules query autogenerated templates derived directly from code.

The flow becomes:

```text
Code (source of truth)
  -> Template engine (autogenerates content)
    -> Template registry (stores typed templates)
      -> contextual.py  (queries Error templates)
      -> discovery.py   (queries Tip templates)
      -> suggestions.py (queries Task templates)
```

Each module retains its existing role — contextual scoring, progressive discovery, and post-workflow suggestions — but its **data source** shifts from hardcoded lists to the template registry.
