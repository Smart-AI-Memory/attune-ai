attune-ai

Give your agent a memory. Make it show receipts. Attune carries decisions, bugs, and lessons across sessions, and verifies every change with probes re-run independently of the agent that claims it finished.

pip install attune-ai

Recommended together with the Claude Code plugin (claude plugin install attune-ai@attune-ai) — both free; an API key is only for direct CLI workflow runs.
