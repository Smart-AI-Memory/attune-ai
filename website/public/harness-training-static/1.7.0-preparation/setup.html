Select a practice runtime

Ask your assistant to check the selected Python executable, installed Harness version and source before running the optional command practice. It should use the noneditable 1.7.0 wheel and pytest in a new environment. Do not replace an existing working tool installation.

The reviewed-wheel procedure identifies the preparation source and wheel. The course check record identifies the separately built wheel used for this course’s fresh checks. A package with the same version number is not evidence of identical bytes.

Build a wheel from a reviewed source checkout

For a maintainer or assistant with this course checkout, select Python 3.12, obtain the build tool, and build into a new directory outside the checkout. Then create a separate environment and install the exact resulting wheel with pytest. Installing dependencies needs network access; the course practice itself makes no provider call.

python3.12 -m build --wheel --outdir /absolute/path/to/new-wheel-directory
python3.12 -m venv /absolute/path/to/new-course-environment
/absolute/path/to/new-course-environment/bin/python -m pip install /absolute/path/to/built-wheel.whl pytest==9.1.1
/absolute/path/to/new-course-environment/bin/python -c "from importlib.metadata import version; print(version('attune-harness'))"

Expect 1.7.0. Activate that environment so python selects its interpreter, then run lesson 2 from the course folder containing practice.py. Windows environment executables are under Scripts; the course’s actual fresh witness is on macOS and does not qualify every Windows shell.
