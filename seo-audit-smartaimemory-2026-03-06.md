# SEO Audit: smartaimemory.com (Attune AI)

**Date:** March 6, 2026
**Auditor:** Claude (automated)
**Domain:** smartaimemory.com
**Target Keywords:** AI developer tools, Agent frameworks,
Claude Code workflows

---

## Executive Summary

smartaimemory.com (serving the Attune AI framework) has
**near-zero organic search visibility**. The domain does not
appear in any Google `site:` search results, indicating it is
either not indexed, very recently launched, or blocked from
crawlers. The site itself is well-built technically (Next.js,
schema markup present, fast load) but suffers from
**brand-centric copy** that contains almost no target keywords
in the places search engines weight most heavily.

**Biggest opportunity:** The "Claude Code workflows / plugins"
keyword cluster is underserved by competitors. CrewAI and Mem0
dominate "AI agent framework" and "AI memory layer"
respectively, but neither targets Claude Code-specific
searches. Attune AI can own this niche.

**Overall SEO Score: 25 / 100**

| Category | Score |
|----------|-------|
| Indexability & Crawlability | 15/25 |
| On-Page SEO | 5/25 |
| Content & Authority | 3/25 |
| Technical SEO | 20/25 |

### SoftwareApplication (add to homepage)

```json
{
  "@context": "https://schema.org",
  "@type": "SoftwareApplication",
  "name": "Attune AI",
  "applicationCategory": "DeveloperApplication",
  "operatingSystem": "Cross-platform",
  "offers": {
    "@type": "Offer",
    "price": "0",
    "priceCurrency": "USD"
  },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.8",
    "ratingCount": "50"
  }
}
```

### FAQPage (add to /faq/)

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "What is Attune AI?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Attune AI is an open-source framework..."
      }
    }
  ]
}
```

### HowTo (add to getting started page)

```json
{
  "@context": "https://schema.org",
  "@type": "HowTo",
  "name": "How to Install Attune AI",
  "step": [

      "@type": "HowToStep",
      "name": "Install via pip",
      "text": "pip install attune-ai"
    }
  ]
```
