# The attune CLI

The attune CLI is the terminal entry point for interacting with attune — running commands for cost tracking, browsing help templates, and managing personal memory and lessons.

## What the CLI does

The CLI is organized into four functional groups, each backed by dedicated command modules:

| Group | Commands | What they do |
|---|---|---|
| **Cost tracking** | `cmd_costs`, `cmd_costs_today`, `cmd_costs_export`, `cmd_costs_reset` | Show, export, and clear cost data for recent sessions |
| **Help browsing** | `cmd_help` | Look up and render documentation templates from the terminal using Rich panels and color (see [Audience-adaptive rendering](concepts/audience-adaptation.md)) |
| **Lessons** | `cmd_remember`, `cmd_forget`, `cmd_lessons` | Add, remove, and list quick-memory lessons by line number or keyword |
| **Personal memory** | `cmd_memory_capture`, `cmd_memory_recall` | Save content to and search cross-session personal memory |

## Routing: how input reaches a skill

When you type a command, `HybridRouter` decides which Claude Code skill to invoke. It does this by matching your input against learned `RoutingPreference` records — each one pairing a keyword with a target skill and optional args.

```
user input → HybridRouter.route()
                 ↓
      match against RoutingPreference records
                 ↓
      return skill invocation dict
```

Preferences are not static. `HybridRouter.learn_preference()` records new keyword-to-skill mappings as you use the CLI, and `get_suggestions()` surfaces partial matches as you type. Over time, routing becomes more accurate because it reflects your actual usage patterns rather than only hard-coded rules.

A `RoutingPreference` record holds five fields: `keyword`, `skill`, `args` (default `''`), `usage_count` (default `0`), and `confidence` (default `1.0`). The `usage_count` and `confidence` fields give the router signal to rank competing matches.

## When the CLI layer matters

You interact with this layer directly whenever you run an `attune` command in the terminal. It also matters when you want to understand why a particular skill was invoked — tracing that back means looking at the `RoutingPreference` records stored in the preferences file that `HybridRouter` loads at initialization.
