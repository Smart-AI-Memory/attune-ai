# How to use deep review

Use this guide when you want to run a multi-pass code review across security, quality, and test coverage in a single call — and get back a consolidated, prioritized report.

## Quick start

```python
from workflows.deep_review import DeepReviewAgentSDKWorkflow

result = DeepReviewAgentSDKWorkflow().execute(path="src/payments")
print(result)
```

This runs three specialized subagents — `security-reviewer`, `quality-reviewer`, and `test-gap-reviewer` — in parallel, then synthesizes their findings into one report. The output includes an overall health score (0–100), severity-ordered findings per domain, and up to ten prioritized next steps.

## Core API

| Class | Purpose |
|-------|---------|
| `DeepReviewAgentSDKWorkflow` | Orchestrates a multi-pass deep review using three Claude Agent SDK subagents; returns a `WorkflowResult` with consolidated findings. |

`execute(**kwargs)` accepts a `path` argument pointing to any directory or file you want reviewed.

## Integration patterns

Call `deep_review` through the MCP tool interface when you need results inside an agent loop:

```python
from workflows.deep_review import DeepReviewAgentSDKWorkflow

# Review a specific module before merging a PR
result = DeepReviewAgentSDKWorkflow().execute(path="src/auth")

# The WorkflowResult contains structured sections you can parse
# or forward directly to a downstream step
print(result)
```

To scope the review to a single file rather than a whole directory, pass the file path directly:

```python
result = DeepReviewAgentSDKWorkflow().execute(path="src/auth/token.py")
```

## What the report contains

The consolidated output always includes these sections, in order:

- **Summary** — overall health score and a short executive summary with finding counts by severity
- **Security** — findings from the security subagent, ordered by severity
- **Quality** — findings from the quality subagent, ordered by severity
- **Test Gaps** — missing or weak test coverage, ordered by priority
- **Suggestions** — the top 5–10 actionable next steps, each linked back to a specific finding
