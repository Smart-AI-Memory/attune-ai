# Quickstart: Install the Attune AI Plugin for Claude Code

Add Attune AI skills to Claude Code in a single command.

## Prerequisites

- Claude Code installed and configured
- Access to the Claude Code plugin marketplace

## Installation

Run the following command in your terminal:

```bash
claude plugin marketplace add Smart-AI-Memory/attune-ai && claude plugin install attune-ai@attune-ai
```

Once complete, **13 skills** are available as slash commands in your Claude Code sessions.

## Verify the Installation

Open a Claude Code session and type:

```
/attune
```

You should see the Attune AI skill menu appear.
