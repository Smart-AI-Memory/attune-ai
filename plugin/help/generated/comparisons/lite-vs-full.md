# Comparison: Attune Lite vs. Attune AI

A guide to choosing between the lightweight plugin (no dependencies) and the full framework.

| Feature | Attune Lite | Attune AI |
|---|---|---|
| Installation | No pip required | `pip install attune-ai` |
| API key required | No | Yes (`ANTHROPIC_API_KEY`) |
| Skills | 5 | 13 |
| Workflows | 5 (via skills) | 17 (CLI + skills) |
| Wizards | 0 | 5 |
| Agent templates | 0 | 14 |
| MCP tools | 0 | 31 |
| CLI | No | Yes (`attune` command) |
| Tier routing | No | Yes (80–96% cost savings) |
| Telemetry | No | Yes (cost tracking) |

## Recommendation

Start with **Attune Lite** if you want Claude Code skills with zero setup overhead. Upgrade to **Attune AI** when you need CLI workflows, cost optimization, or access to the full MCP toolset.
