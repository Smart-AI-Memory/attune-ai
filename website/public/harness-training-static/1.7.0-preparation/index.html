Follow the learning path

  1. Turn an idea into a useful result

    Choose a result you can explain and a first version you can check.

  2. Build your first report

    A useful result. Clear boundaries. Evidence you can inspect.

  3. Come back tomorrow

    Recover the goal, read what happened and choose a justified next action.

  4. Decide whether to trust the report

    Check the answer. Read the evidence. Make a reasoned decision.

  5. Make the tool usable

    Give another person a clear route to a useful local report.

  6. Make it work for your needs

    Choose one variation and prepare the next bounded change.
