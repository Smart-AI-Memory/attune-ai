What the inspected base install supplies¶

Install Harness 1.8.1 with Python 3.12 or later. The base package installs these dependencies. It includes attune-forms for the Harness forms workflow.

Package Pinned version Used for
attune-forms 0.17.0 Rendered forms and answer collection
attune-rag 1.2.0 Local source retrieval
attune-verify 0.6.0 Supported verification checks
mcp 2.2.0 MCP integration
tiktoken 0.12.0 Token counting
packaging 26.3 Version compatibility checks
certifi 2026.10.23 TLS certificate authorities
cryptography 50.0.2 Cryptographic operations

Keep these versions when adding integrations to 1.8.1. See the signed release's package metadata for the exact dependency declarations.

Add optional integrations only when needed¶

Extra Release dependency pins Requirements
redis redis 5.3.1 A separate Redis service that meets the operation's requirements.
voyage voyageai 0.5.0, lancedb 0.38.0, pyarrow 25.0.1, jsonschema 4.26.0, httpx2 2.13.0 Voyage retrieval requires credentials and separate approval for paid calls.
memory-native anthropic 1.6.0, httpx2 2.13.0 Experimental native memory. See the qualification guide for the tested profiles.
plan-oauth Authlib 1.9.3, joserfc 1.8.0 The openai-plan adapter requires macOS arm64 with CPython 3.12.2. See participant funding for consent and execution requirements.
all redis and voyage Select memory-native or plan-oauth separately when required.

For example, install the Redis extra in a selected, isolated Python 3.12 environment:

python -m pip install 'attune-harness[redis]==1.8.1'

For uv or Windows instructions, follow the 1.8.1 installation guide.

Integrate with a host¶

  • Codex plugin and standalone skill: prepare the workflow plugin from the release source and install the Python runtime separately.
  • Claude Code setup: install the host plugin separately and check its version.
  • CLI and MCP guide: configure participants, use task commands and set up MCP. Keep Harness and Attune AI in separate Python environments because they require different MCP SDK versions.

1.6.0 Redis requirements and limits¶

The 1.6.0 release record documents the original Redis 7.4.7 and Search 2.10.20 checks on macOS arm64. For 1.8.1, use the operation-specific Redis requirements linked above. Keep existing service data, memory writers, and session hooks while checking an upgrade.
