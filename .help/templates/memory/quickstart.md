# Quickstart: Attune Memory

Store and retrieve persistent memory in your project using `ClaudeMemoryLoader`.

```python
from attune.memory import ClaudeMemoryLoader

loader = ClaudeMemoryLoader()
context = loader.load_all_memory()
print(context)
```

**Result:** The combined contents of all `CLAUDE.md` memory files found at the enterprise, user, and project levels, printed to your console.

## Prerequisites

- The project is cloned and installed locally
- A `.claude/CLAUDE.md` file exists in your project root (or run `create_default_project_memory()` to generate one — see Step 1)

## Step 1: Create a project memory file

If your project doesn't have a `.claude/CLAUDE.md` yet, generate one:

```python
from attune.memory import create_default_project_memory

create_default_project_memory(project_root=".")
```

This writes a default `CLAUDE.md` to `.claude/CLAUDE.md` in the current directory.

## Step 2: Configure and load memory

Use `ClaudeMemoryConfig` to control which memory levels are loaded:

```python
from attune.memory import ClaudeMemoryLoader, ClaudeMemoryConfig

config = ClaudeMemoryConfig(
    enabled=True,
    load_enterprise=True,
    load_user=True,
    load_project=True,
)
loader = ClaudeMemoryLoader(config=config)
context = loader.load_all_memory(project_root=".")
print(context)
```

**Result:** A single string containing memory content merged from all enabled levels. An empty string means no `CLAUDE.md` files were found at the configured paths.

## Step 3: Check what was loaded

Confirm which files contributed to the result:

```python
loaded = loader.get_loaded_files()
print(loaded)
# Example: ['.claude/CLAUDE.md']
```

## Step 4: Verify Redis availability (optional)

If your workflow uses short-term Redis-backed memory, confirm the subsystem is reachable before using it:

```python
from attune.memory import is_redis_available

print(is_redis_available())
# True
```

If this returns `False`, Redis is not installed or not running. The `ClaudeMemoryLoader` file-based workflow in Steps 1–3 works without Redis.
